# Public distribution boundary

This repository contains only public Harvest Borough website source, documentation and approved downloadable releases. Do not place private game source, backend configuration, host addresses, credentials or signing material here.

Only the site-owning agent may edit the Sites checkout or invoke Sites operations. Preserve `.openai/hosting.json` and reuse its project identifier. Use the Sites building and hosting skills. Asset and research subagents do not own the site.

Never invent a download URL, release version, update time, screenshot, purchase price, or completed-feature claim. Real screenshots show the exact built game at a recorded revision. An original logo illustration is not a gameplay screenshot.

Each search has its own adjacent anchored regex-builder entry and isolated state; record unavailable advanced capability honestly until implemented. Keep the roadmap current and unverified features unchecked. Public content uses ordinary professional wording.
